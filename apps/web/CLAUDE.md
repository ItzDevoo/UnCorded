# Frontend — apps/web

SolidJS + Vite + Tailwind CSS v4. This is NOT React.

## Critical

- SolidJS: createSignal, createStore, createEffect, Show, For
- No useState, useEffect, Array.map in JSX, or virtual DOM patterns
- Tailwind semantic color tokens only — no raw colors
- Auth is session-based: `credentials: 'include'` on all API calls
- Lazy-load all route-level pages
